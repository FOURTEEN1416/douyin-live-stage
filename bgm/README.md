# 背景音乐放这里

把 mp3 / wav / m4a / flac 丢进这个目录就行，程序启动时会把它们**按文件名顺序拼成一条循环流**，
和大肥鱼的语音实时混音（不会互相打断）。

- 音量在 `.env` 里调：`BGM_VOLUME=0.28`（0~1，默认 0.28，人声清楚又不盖过音乐）
- 首尾自动加 1.5 秒淡入淡出，循环接缝不会"咔"一下
- 想换歌：删掉旧的、放新的，重启 `run.cmd` 生效

## 版权提醒

**别直接放流行歌原曲**。抖音直播会做音频指纹识别，放热门原曲大概率被判侵权——
轻则这段音频被静音，重则限流/断流。

安全的选择：
1. **抖音直播伴侣自带的"背景音乐"**（对接官方曲库，有授权，最稳）
2. 免版权音乐站：Pixabay Music、Free Music Archive、YouTube Audio Library
3. 风格建议：lo-fi、轻电子、chill、钢琴 —— 适合写代码的场景，也不容易触发识别
